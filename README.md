# Boomify

Boomify is an experimental Windows DAW focused on one priority: **make music without fighting the interface**.

## v0.0.1 — First Sound

Current prototype:
- native Windows interface
- 60–220 BPM
- Play / Stop (Space)
- 16-step kick drum machine
- synthesized kick: no external sample or VST required
- automatic Windows build script

## Build on Windows

Double-click `build.bat`.

The script detects the Microsoft C++ toolchain and CMake. If the required Build Tools are missing, it can install them through WinGet. Once compiled, Boomify launches automatically.

> Early development prototype. Expect rapid changes.
